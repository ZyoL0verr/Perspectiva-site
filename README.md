# Site Perspectiva — prévia

## Como abrir no VS Code
1. Extraia esta pasta.
2. Abra a pasta no VS Code.
3. Abra `index.html` no navegador ou use a extensão **Live Server**.
4. Edite `style.css` para alterar cores, tamanhos e layout.

Arquivos:
- `index.html` — estrutura do site
- `style.css` — visual/identidade
- `script.js` — interações básicas

A paleta foi baseada em branco, bege, marrom e preto, com uma estética editorial e minimalista.
